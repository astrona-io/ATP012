# ATP012 — Certified Argo Project Associate (CAPA)

One stage per exam domain, connected through `path.yaml` to a training series
repository. Every series has layered readings, private playgrounds, graded labs
and knowledge checks; all labs and playgrounds were run with the Astrona CLI on
2026-11-07. The course registration in `astrona-content` is **beta**.

This exam is part of the current Golden Kubestronaut requirements.

| Stage | Domain | Weight | Series |
| --- | --- | --- | --- |
| STG001 | Argo Workflows | 36% | [ATS060](https://github.com/astrona-io/ATS060) |
| STG002 | ARGO CD | 34% | [ATS061](https://github.com/astrona-io/ATS061) |
| STG003 | Argo Rollouts | 18% | [ATS062](https://github.com/astrona-io/ATS062) |
| STG004 | Argo Events | 12% | [ATS063](https://github.com/astrona-io/ATS063) |
